**Python Text-Based Adventure Game**

This project is a Python-based text adventure game that allows users to navigate a map, collect items, and complete an objective before reaching the final room. The application demonstrates core programming concepts, algorithmic thinking, and foundational software design principles.

This project served as the original version of a larger capstone project that was later expanded into a Java-based application with added features such as database integration and user authentication. You can view the enhanced Java version [here](https://github.com/KnHoehn/Python-Text-Based-Game)

 

**Overview**

The game challenges players to explore different areas, collect required items, and reach the final destination (the boss room). If the player reaches the final room without collecting all items, the game is lost.

The application uses a structured map system and decision-based navigation, requiring users to make logical choices to progress through the game.

This project focuses on implementing game logic, managing state, and designing a modular structure for navigation and inventory tracking.

**Game Design**

The application uses a structured layout where each room is connected to others, allowing players to navigate through the game world.

Core design elements include:

- A dictionary-based system to represent room connections
- Conditional logic to handle player movement and actions
- Inventory checks to determine game outcomes
- This structure supports scalable expansion and was later used as the foundation for a more advanced Java-based version of the game.

 

**How to Run the Project**

1. Install Python (version 3.x recommended)
2. Clone or download the repository
3. Open a terminal or command prompt
4. Navigate to the project directory
5. Run the game using the command: python TextBasedGame.py
